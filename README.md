# jumiaClone


I built a static clone of the Jumia e-commerce website using HTML and CSS. This project focused on recreating the layout and design of the homepage and product sections to sharpen my frontend skills in structure and styling.



## Deployment

To deploy this project run

```bash
  Yarn dev 
```
